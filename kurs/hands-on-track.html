Übung: To-do-Skill für das Second Brain

Auftrag

Einen Skill «To-do» bauen, der eine Aufgabe als Markdown-Eintrag im Second Brain ablegt.

  • Aufgabe in einem Satz nennen
  • Claude Code legt den Eintrag als Markdown an
  • Format prüfen und im Dialog korrigieren
  • Das gelungene Vorgehen als Skill festhalten (SKILL.md mit Template)

Übung: Bookmark-Skill für das Second Brain

Auftrag

Einen Skill «Bookmark» bauen, der einen Link verarbeitet und als Markdown ablegt.

  • Link holen
  • Kurzzusammenfassung schreiben
  • Tags vergeben
  • Als Markdown-Datei im Second Brain ablegen

Übung: Eigener Skill mit Connector und Template

Auftrag

Aus einem Prompt, der schon gut funktioniert hat, einen eigenen Skill bauen. Einen Connector und ein eigenes Template einbinden.

  • Ausgangspunkt: ein Prompt, dessen Resultat sich wiederholen soll
  • Connector wählen: Google Mail, Drive, Kalender oder Dropbox
  • Template wählen oder selbst festlegen

Weitere Skills aus gelungenen Prompts

  • Wochenrückblick
  • Antwortmail im eigenen Ton
  • Präsentation im Corporate Design
  • Lernkarten
  • Checkliste oder Rezept

Hinweis

Ein Meeting-Skill fehlt bewusst. Er ist von Copilot bereits bekannt.

Station 3 · Apps

Vom Styleguide zum Brain Dashboard

Styleguide aus einer Vorlage ableiten

  • Vorlage oder Screenshot einer Website, die gefällt
  • Claude Code leitet eine Styleguide-Datei in Markdown ab
  • Inhalt: Farben, Schriften, Abstände, Ecken, Schatten, Ton
  • Eine Testseite zeigt das Ergebnis, Korrekturen laufen im Dialog

Verbotsliste gegen den Standard-AI-Look

Der Styleguide legt fest, was es gibt. Die Verbotsliste legt fest, was es nicht gibt.

Keine Verläufe

Flächen bleiben einfarbig.

Keine Standardschrift

Die Schrift kommt aus dem Styleguide.

Keine Emojis als Icons

Icons sind echte Symbole.

Framework und shadcn/ui

  • Ein Framework liefert fertige Bausteine für Oberflächen
  • shadcn/ui ist ein solches Framework für Webseiten
  • Gezeigt wird es an einer einzigen Komponente: der Karte
  • Claude Code setzt das Projekt im Ordner dev auf und startet den Server selbst

Skill «Neue App mit shadcn»

Style übersetzen

Server starten

Claude Code startet den lokalen Webserver

Übung: Brain Dashboard im eigenen Style

Auftrag

Ein Dashboard für das Second Brain bauen, mit Karten für To-dos, Bookmarks und Notizen. Die Inhalte kommen aus den Markdown-Dateien, die Gestaltung aus dem eigenen Styleguide.

  • Ausgangspunkt: Second Brain mit Markdown für To-dos und Bookmarks
  • Neue App mit dem Skill «Neue App mit shadcn» anlegen
  • Karten aus den Markdown-Dateien füllen

Auswertung der Dashboards

  • Die Dashboards zeigen
  • Besprechen, was gut gelungen ist und was nicht
  • Festhalten, welcher Prompt zum nächsten Skill wird
